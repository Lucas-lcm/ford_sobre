Formação em desenvolvimento web

Um curso, um projeto, um repositório que cresce a cada aula.

O Ford Enter é um programa de capacitação em tecnologia que leva pessoas sem experiência prévia até a construção de uma aplicação web completa. Este repositório é o ponto de partida: copie-o para a sua máquina e continue o desenvolvimento a partir daqui.

O que é o Ford Enter

Uma iniciativa de formação gratuita que combina aulas práticas, acompanhamento de instrutores e um projeto real construído do começo ao fim pela turma.

  • Aprender fazendo

    Cada conteúdo novo entra direto no projeto da turma. Nada de exercício solto: o que você estuda hoje aparece na página amanhã.

  • Ferramentas de mercado

    Terminal, Git, GitHub, VS Code e publicação na nuvem. O mesmo fluxo que uma equipe de desenvolvimento usa no dia a dia.

  • Portfólio desde o início

    Ao final do programa, o histórico de commits mostra a sua evolução e o projeto publicado vira o primeiro item do seu portfólio.

A trilha, módulo a módulo

A sequência é cumulativa: cada módulo usa o que foi construído no anterior.

  1. 01

    Front-end: HTML e CSS

    Tags, HTML semântico, acessibilidade, prototipagem, box model, posicionamento, Flexbox, CSS Grid e design responsivo.

  2. 02

    Versionamento e publicação

    Git e GitHub no fluxo de trabalho real: clonar, versionar, enviar alterações e publicar o site para o mundo.

  3. 03

    Back-end com Python

    Lógica de programação, orientação a objetos e construção de uma API própria para servir os dados da aplicação.

  4. 04

    JavaScript e React

    Interatividade no navegador, componentes, rotas e consumo da API criada no módulo anterior.

O projeto da turma: catálogo de veículos

Todo o curso gira em torno de uma única aplicação. Ela começa como uma página estática com a lista de modelos, ganha interatividade com JavaScript, passa a buscar os dados de uma API feita pela própria turma e termina como uma aplicação em React.

Este repositório é a semente desse projeto. Clone agora e, a cada aula, traga as novidades com git pull.

Trazendo este projeto para a sua máquina

Abra o terminal na pasta onde você guarda seus projetos e siga os passos abaixo.

1. Copiar o repositório

O git clone baixa o projeto inteiro, com todo o histórico de versões, e cria uma pasta com o nome do repositório.

git clone https://github.com/SEU-USUARIO/projeto-ford-enter.git
cd projeto-ford-enter

2. Conferir onde você está

Antes de mexer em qualquer arquivo, veja a situação do repositório e o histórico já existente.

git status
git log --oneline

3. Atualizar durante a aula

Quando o instrutor enviar uma alteração, o git pull traz as novidades para a sua cópia local sem apagar o que já existe.

git pull origin main

4. Registrar o seu trabalho

Depois de editar os arquivos, salve a sua versão no histórico com uma mensagem que explique o que mudou.

git add .
git commit -m "Ajusta cores do catalogo"

Deu conflito no git pull?

Isso acontece quando você e o instrutor alteraram as mesmas linhas. Salve o seu trabalho com git commit antes de puxar as novidades e, se o aviso aparecer, abra o arquivo marcado: o Git mostra as duas versões e espera que você escolha qual fica.
